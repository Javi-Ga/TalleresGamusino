**3. Cómo abrir el proyecto**
Descomprimir el archivo Grupo_UD2_Talleres.zip.
Abrir el archivo index.html haciendo doble clic sobre él en cualquier navegador web (Chrome, Firefox, Edge, Safari).
Navegar por el flujo completo de las 4 pantallas enlazadas: index.html (Ver más detalles) -> informacion.html (Inscribirme ahora) -> inscripcion.html (Enviar) -> confirmacion.html (Ver talleres). (Nota: Se requiere conexión a Internet para cargar las fuentes de Google Fonts, los iconos de Font Awesome y las imágenes de Unsplash).

**4. Funciones simuladas en el prototipo**
Al tratarse de un prototipo en HTML y CSS sin base de datos ni servidor, se han simulado las siguientes acciones:
-Cabecera y pie de página: El buscador (Search for...), los botones de cambio de idioma y perfil de usuario, el enlace de "Contacto" y los iconos de redes sociales son elementos visuales y no ejecutan acciones.
-Listado de talleres (index.html): El selector de filtro por temática, el calendario de fechas ("February 2021") y las flechas/puntos del carrusel de talleres son estáticos. La tarjeta del taller destacado ("Guardianes digitales") es la que enlaza con la vista de detalle real (informacion.html).
-Formulario y confirmación (inscripcion.html y confirmacion.html): El envío del formulario redirige directamente a la pantalla de confirmación (confirmacion.html) sin almacenar los datos en una base de datos ni enviar un correo electrónico real.
